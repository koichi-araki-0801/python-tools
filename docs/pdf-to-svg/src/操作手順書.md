このツールは、PDF をきれいな画像データ（SVG）に変換するためのものです。むずかしい知識は不要です。画面の **1 → 2 → 3 → 4** の順に、ボタンを押して進めるだけで完成します。

# 1. はじめに

## 1.1 このツールでできること

- PDF を、あとから文字を検索・修正できる画像ファイル（**SVG**）に変換します。
- 表の見出しなどの**言葉を、あらかじめ登録した対応表（辞書）でまとめて置き換えられます**（ボタンで適用。例: 「Header A」→「見出し A」）。
- いらない部分を**消す**、範囲を囲んで**まとめて消す**、**枠線を足す**、といった簡単な編集ができます。

できあがった SVG は軽いファイルで、印刷や資料作成にそのまま使えます。

## 1.2 用語のかんたんな説明

本書に出てくる言葉は、次の意味で使っています。わからなくなったらここへ戻ってください。

| 言葉 | 意味 |
|---|---|
| SVG | 画像ファイルの形式のひとつです。拡大してもぼやけず、中の文字をあとから検索・修正できます。 |
| 辞書 | 「元の言葉 → 置き換え後の言葉」の対応表です。このツールに登録しておくと、ボタン 1 つでまとめて置き換えられます。 |
| 置換（ちかん） | 言葉を別の言葉に置き換えることです。 |
| 再適用 | 辞書をページに当てる操作です。初めて当てるときも同じ「再適用」ボタンを使います。 |
| スキップ | そのページの置換の確認を省略することです。スキップしたページは、書き出しのときに除外できます。 |
| JSON（ジェイソン） | 辞書を保存したファイルの形式です。「JSON書き出し」で作ったファイルを、別の PC で「JSON読み込み」すると同じ辞書が使えます。 |
| ダブルクリック | マウスの左ボタンをすばやく 2 回押すことです。 |
| ドラッグ | マウスの左ボタンを押したまま動かすことです。 |
| ドラッグ&ドロップ | ファイルをドラッグで持ち上げ、目的の場所で指を離して置くことです。 |
| ダウンロードフォルダ | パソコンに最初から用意されている保存場所です（例: `C:\Users\<お名前>\Downloads`）。できあがったファイルはここに入ります。 |
| ZIP（ジップ） | 複数のファイルを 1 つに束ねた圧縮ファイルです。右クリック →「すべて展開」で中身を取り出せます。 |

# 2. 起動のしかた

1. 配布された「PdfToSvg」フォルダを開きます。
2. その中の **「PdfToSvg.exe」** を**ダブルクリック**します。
3. そのまま少し待ちます。
4. 「PdfToSvg」というアプリの画面が開いたら、準備完了です。

> [!INFO] 画面が開かないときは、20〜30 秒ほど待ってから、もう一度ダブルクリックしてください。それでも開かないときは、7 章「うまくいかないとき」をご覧ください。

# 3. ステップ 1：PDF を選ぶ

最初の画面で、変換したい PDF を選びます。複数の PDF をまとめて選ぶこともできます。

![ステップ 1：PDF を選ぶ画面](images/step1_select.png)

1. 画面中央の **「ファイルを選ぶ…」** ボタンを押します。
2. 開いた画面で、変換したい PDF をクリックして選びます（Ctrl キーを押しながらクリックすると複数選べます）。
3. **「開く」** を押します。
4. 選んだ PDF が画面下の一覧に表示されたことを確認します。
5. 右下の **「次へ」** を押します。

> [!TIP] PDF を青い枠の上に**ドラッグ&ドロップ**しても選べます。まちがえて選んだときは、一覧の右にある **×** を押すと取り消せます。

> **「次へ」が押せないとき**は、まだ PDF が 1 つも選ばれていません。先に PDF を選んでください。

# 4. ステップ 2：言葉を置き換えて確認する

この画面では、辞書に登録済みの言葉をページに適用し、置き換わった箇所を目で確認します。
言葉の置き換えは**自動では行われません**。「辞書」タブのボタンで適用します。

![ステップ 2：置換された箇所の確認（右側に置換の一覧）](images/step2_replace.png)

1. 右側の **「辞書」** タブを開き、**「このページのみ再適用」** を押します。表示中のページに辞書が適用されます。例では「Header A」が「**見出し A**」に置き換わります。
2. 右側の **「確認」** タブの一覧で、置き換わった内容（Header A → 見出し A）を確認します。
3. 一覧の行をクリックすると、ページ上の該当箇所が**青く光り**、場所がわかります。
4. 内容がよければ **「確認しました」** を押します。直すところがなければ **「スキップ」** でもかまいません。
5. ページが複数あるときは、次のページも同じように適用・確認します。**まとめて反映したいときだけ**「全ファイルに再適用」を押します（選んだすべての PDF の全ページに一度に適用されます）。
6. すべて確認できたら、右下の **「次へ」** を押します。

## 4.1 新しい言葉を辞書に登録する

置き換えたい言葉を自分で追加できます。登録したら、再適用ボタンでページに反映します。

![ステップ 2：辞書タブ（用語の追加と登録一覧）](images/step2b_dict.png)

1. 右側の **「辞書」** タブをクリックして開きます。
2. 中央のページ上で、置き換えたい見出しの文字を**クリック**します。すると、その言葉が「元の語」の欄に自動で入ります。
3. 「置換後」の欄に、新しい言葉を入力します。
4. **「辞書に追加」** を押します。
5. **「このページのみ再適用」** を押します。表示中のページに反映されます。ほかのページ・ファイルにもまとめて反映したいときは **「全ファイルに再適用」** を押します。

> [!TIP] 見出しが 2 行に折り返されているときは、先に **「クリック取り込みで折返しを連結」** にチェックを付けてから文字をクリックすると、**クリック 1 回**で 1 文まるごと「元の語」に入ります。この方法で登録した言葉には一覧に「連結」の印が付き、再適用のときに 2 行をまとめて置き換えます（チェックなし・手入力で登録した言葉は 1 行ずつの置き換えだけに使われます）。「元の語」を手で入力してもかまいません。

> [!INFO] 再適用は、表の見出しか本文かを問わず**ページ内のすべての文字**が対象です。辞書に登録した言葉と一致した箇所がまとめて置き換わります。

## 4.2 置き換えを 1 か所だけ戻す / 当てる

確認一覧（右側の「確認」タブ）の各行には、ページ上の同じ番号のマーカーが対応しています。同じ言葉が何度も出てくるページでも、番号を見れば「どこの置き換えか」が分かります。行にマウスを乗せると、その箇所がページ上で枠で強調されます。

| 操作 | 内容 |
|---|---|
| **戻す** | その 1 か所だけを置き換え前の言葉に戻します（Undo で取り消せます）。戻した行は「未置換」として一覧に残ります。 |
| **置換** | 未置換の行を、その 1 か所だけ置き換えます。 |

> [!INFO] 「戻す」で戻した箇所は、次に「再適用」を押すとまた置き換わります。戻したままにしたいときは、再適用のあとにもう一度「戻す」を押してください。

## 4.3 黄色いバーが出たとき（確認していないページが残っている）

未確認のページが残ったまま「次へ」を押すと、画面の下に黄色いバーが出ます。確認漏れを防ぐための仕組みです。

![未確認のページが残っているときに出る黄色いバー（画面下）](images/step2d_guard.png)

- 確認に戻るとき: **「最初の未確認へ」** を押します。該当ページに移動します。
- すべて確認不要のとき: **「未確認をすべてスキップして進む」** を押します。

# 5. ステップ 3：いらない部分を消す・枠線を足す

この画面では、いらない部分を消したり、枠線を足したりできます。編集が不要なら、そのまま「確認しました」（または「スキップ」）で先へ進んでかまいません。

![ステップ 3：削除・範囲削除・枠線の編集画面](images/step3_edit.png)

## 5.1 1 か所ずつ消す（選択 → 削除）

1. 左上の **「選択」** が押された状態であることを確認します。
2. 消したい部分（文字や線）をクリックします。
3. **「削除」** ボタンを押します。選んだ部分が消えます。

## 5.2 範囲を囲んでまとめて消す（範囲削除）

1. **「範囲削除」** ボタンを押します。
2. 消したい範囲を、マウスで四角く**ドラッグ**して囲みます。
3. 指を離すと、囲んだ範囲の中身がまとめて消えます。

![範囲削除：マウスで囲んでいる途中の画面（青い四角の中がまとめて消えます）](images/step3c_region.png)

## 5.3 枠線を足す

1. **「枠線」** ボタンを押します。
2. 必要なら色と太さを選びます。
3. 枠を付けたい場所を、マウスで四角く**ドラッグ**して囲みます。
4. 指を離すと、その場所に枠線が追加されます。

![枠線：ドラッグした場所に黒い枠線が追加された画面](images/step3b_border.png)

## 5.4 やり直したいとき

- まちがえたら、右上の **「戻す」** ボタン（または **Ctrl+Z**）で 1 つ前に戻せます。
- 戻しすぎたら **Ctrl+Y** で進め直せます。

各ページの編集が済んだら **「確認しました」**（不要なら **「スキップ」**）を押し、右下の **「書き出しへ」** を押します。

# 6. ステップ 4：SVG として保存する

最後に、できあがった SVG をファイルとして保存します。

![ステップ 4：書き出し画面](images/step4_export.png)

1. 「書き出す範囲」を選びます。ふつうは **「全ページ」** のままで大丈夫です。
   - 「表示中のページのみ」: いま開いている 1 ページだけ。
   - 「スキップを除く」: ステップ 2・3 でスキップしたページを除きます。
   - 「ページを指定」: 「1-5, 8」のように番号で指定できます。
2. 右下の緑色の **「SVG に書き出す」** ボタンを押します。
3. 完了すると「○個の SVG を書き出しました。」と表示されます。
4. **「ダウンロード」フォルダ**を開いて、ファイルができていることを確認します。

> [!INFO] 保存先を選ぶ画面は出ません。ファイルは必ず**ダウンロードフォルダ**に入ります（リモートデスクトップ環境でも安定して動かすための仕様です）。

> **ファイル名**は「元のファイル名_p1.svg、_p2.svg …」のように、ページごとに自動で付きます。**2 ページ以上をまとめて書き出したときは ZIP 1 ファイル**（中に全ページ分の SVG）になります。ZIP は右クリック →「すべて展開」で開けます。

# 7. うまくいかないとき（よくある質問）

| こまりごと | 対処 |
|---|---|
| アプリの画面が開かない | 20〜30 秒待ってから、もう一度「PdfToSvg.exe」をダブルクリックしてください。直らないときは、ログファイル `C:\Users\<お名前>\AppData\Local\PdfToSvg\data\logs\startup.log` を添えて、情報システム担当へご連絡ください（見つからないときは、アプリのフォルダ内の `data\logs\startup.log` を探してください）。 |
| 「次へ」が押せない | ステップ 1 で PDF がまだ選ばれていません。先に PDF を選んでください。 |
| PDF を選ぶ画面で固まる | エクスプローラーから PDF をアプリの画面へ**ドラッグ&ドロップ**してみてください。 |
| 黄色い警告バーが出た | 未確認のページが残っています。「最初の未確認へ」で戻って確認するか、「未確認をすべてスキップして進む」を押します（4.3 節）。 |
| 言葉が置き換わらない | 「辞書」タブで言葉を登録し、**「このページのみ再適用」**（全部にまとめて反映するなら「全ファイルに再適用」）を押してください（4.1 節）。 |
| 1 か所だけ置き換えを戻したい / 当てたい | 確認一覧の行にある「戻す」「置換」ボタンを使います（4.2 節）。 |
| 2 行に折り返された見出しが置き換わらない | 「クリック取り込みで折返しを連結」にチェックを付けてから見出しをクリックし、登録し直してください。一覧に「連結」の印が付いた言葉だけが 2 行まとめて置き換わります（4.1 節の TIP）。 |
| まちがえて消してしまった | 右上の「戻す」ボタン（または Ctrl+Z）で戻せます（5.4 節）。 |
| 保存したファイルが見つからない | 保存先は**「ダウンロード」フォルダ固定**です（例: `C:\Users\<お名前>\Downloads`）。画面上部に出るダウンロード通知からも開けます。 |
| 保存先を選びたい | 選べない仕様です（リモートデスクトップ環境で安定させるため）。ダウンロードフォルダから目的の場所へコピーしてください。 |
| 操作の途中で画面が突然閉じた | もう一度起動すれば続きから作業できます（作業中の PDF は選び直してください）。繰り返す場合は、いちばん上の行と同じログを添えてご連絡ください。 |
| 別の PC でも同じ辞書を使いたい | 8 章「辞書をほかの PC と共有する」をご覧ください。 |

# 8. 辞書をほかの PC と共有する

登録した辞書は、ファイルにして他の方へ渡せます。「辞書」タブのいちばん下に、共有用のボタンが並んでいます。

![辞書タブ下部の共有ボタン（JSON書き出し / JSON読み込み）](images/step2c_dict_share.png)

**渡す側の操作**:

1. 「辞書」タブを開きます。
2. いちばん下の **「JSON書き出し」** を押します。
3. 辞書ファイル（dictionary.json）がダウンロードフォルダに保存されます。
4. そのファイルを、共有フォルダやメールで相手に渡します。

**受け取る側の操作**:

1. 「辞書」タブを開きます。
2. いちばん下の **「JSON読み込み」** を押します。
3. 受け取ったファイルを選びます。
4. 辞書が取り込まれ、一覧に追加されたことを確認します。

# 9. 補足（開発・管理ご担当者向け）

事務ご担当者さまは読み飛ばしてかまいません。

- ソースからの開発起動は、リポジトリの `pdf-to-svg\run.bat` をダブルクリックします（黒いコンソール窓が開きますが、作業中は閉じないでください。窓を閉じるとアプリも終了します）。
- 配布用 exe のビルド手順・端末への展開・辞書ファイルの一括配布・ログの見方は、別冊「PdfToSvg 配布・運用手順書」を参照してください。
- ツール内部の構造（変換の仕組み・辞書の照合ルールなど）は、別冊「PdfToSvg 詳細設計書」を参照してください。
