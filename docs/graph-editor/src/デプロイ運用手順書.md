本書は SVG ラベル位置エディタ（graph-editor）を社内端末へ配布・運用するための手順をまとめる。内部構造は別冊「SVG ラベル位置エディタ 詳細設計書」を参照。

# 1. 配布方針

ブラウザエンジンを同梱せず OS 標準の Microsoft Edge を使うため、配布物は**単一 exe（~10MB）**。`LabelEditor.exe` をそのまま配るだけでよい（付属フォルダ・インストール不要）。Python も WebView2 も不要で、Windows 10 / 11 で起動できる。

# 2. 開発実行（ビルド前の動作確認）

```
python -m pip install -r requirements.txt
python app.py
```

実行は標準ライブラリのみ（`requirements.txt` の追加依存は `pyinstaller` のビルド時のみ）。

# 3. exe をビルド

ブラウザエンジンを同梱しないため、**前提作業は不要**（OS の Edge を使う）。`graph-editor\scripts\build.bat` をダブルクリックするだけ。

```
graph-editor\scripts\build.bat
```

`dist/LabelEditor.exe`（単一ファイル・~10MB）が生成される。手動で実行する場合:

```
python -m PyInstaller --noconfirm --onefile --windowed --name LabelEditor ^
  --add-data "resources/web/ui.html;." ^
  --add-data "resources/web/styles.css;." ^
  --add-data "resources/web/js;js" ^
  --add-data "resources/web/lib/leader_geom.cjs;lib" ^
  app.py
```

`--add-data` で `resources/web/` の `ui.html` 一式を exe に同梱する点が要点。

# 4. 配布・起動

1. 生成した `dist/LabelEditor.exe` を共有フォルダや配布メディアで対象端末へ渡す。
2. 受け取った端末では任意の場所に置いて `LabelEditor.exe` をダブルクリックするだけ。
3. Microsoft Edge のアプリ窓が開く。

> [!NOTE] **共有フォルダ・ネットワークドライブに置いたまま起動してもよい**（onefile 配布のため
> 実行時の展開先はローカルの一時領域で、診断ログも `%LOCALAPPDATA%\LabelEditor\data\logs` に
> 出る。exe の隣には何も書かない）。ただし共有に置く場合、配布フォルダの ACL は**利用者へは
> 読み取り＋実行のみ**（書き込みは情報システム担当のみ）にすること。誰でも書ける共有に置いた
> exe は差し替えによる任意コード実行の入口になる。

# 5. 運用・トラブル対応

| 事象 | 対処 |
|---|---|
| アプリ窓が開かない | 数十秒待って再起動。`%LOCALAPPDATA%\LabelEditor\data\logs\startup.log` に起動診断が出るので確認（ユーザー領域が使えない端末では exe 隣の `data\logs`）。Edge が見つからない場合は既定ブラウザで開く（`127.0.0.1` の secure context が必要）。 |
| VDI/リモートデスクトップでアプリ窓がクラッシュする | 本ビルドは端末標準の「管理された」既定 Edge と同じ構成で開き（特殊フラグ無し）、ファイルの開く/保存もネイティブダイアログを使わないため VDI でも安定するよう対策済み。なお落ちる場合は `%LOCALAPPDATA%\LabelEditor\data\logs\startup.log` を情報システム担当へ。Edge 側の詳細が要るときは、環境変数 `LABELEDITOR_EDGE_LOG=1` を設定してから再現させ、`%LOCALAPPDATA%\LabelEditor\logs\edge.log` を渡す（既定では出力されない。既定プロファイルで開くため、常時出力すると Edge セッション全体の記録が利用者の端末に溜まり続ける）。 |
| 端末に Edge が無い | Edge を導入（Win10/11 は標準搭載）。 |
| ファイルの開く / 保存 | 従来型ダイアログ（開く）＋ダウンロード（保存）。SVG をウィンドウへ**ドラッグ＆ドロップ**でも開ける。保存先はブラウザのダウンロードフォルダ固定（VDI 安定化のため）。 |
| 保存しても元が変わらない | 仕様。元ファイルは上書きされず別名（ダウンロード）保存される。 |

> [!INFO] 窓を閉じると（プロセス終了 / `pagehide` の `/quit` ビーコン）裏のローカルサーバも自動終了する。黒いコンソール窓は表示されない（`--windowed` ビルド）。
