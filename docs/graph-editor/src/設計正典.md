graph-editor（LabelEditor）の設計正典。pie-chart が生成した SVG のラベル・引出線（leader）を
人手で微調整する Edge シェル型ローカルアプリ（Python 簡易サーバ + vanilla JS、PyInstaller で
単一 exe 配布）。詳細は別冊「詳細設計書」、検証コマンドは下記チェックリスト参照。

## 全体像

<!-- ノードラベルは短い 2 行構成（改行は `<br/>`）に保つ。長い行は CJK 幅の過小計算で見切れる。 -->

```mermaid
flowchart LR
  PIE["入力<br/>pie-chart 生成 SVG"] --> UI["Edge アプリ窓<br/>ui.html + 13 JS"]
  APPY["app.py<br/>127.0.0.1 静的配信"] --> UI
  UI --> EDIT["編集<br/>Editor / LabelState"]
  EDIT --> BAKE["座標焼き込み<br/>bakeSvg"]
  BAKE --> OUT["保存<br/>ダウンロード固定"]
  UI -. "/ping 10秒毎 · /quit" .-> APPY
```

`app.py` は静的配信とライフサイクル管理のみ。編集ロジックは全部ブラウザ側 JS が担う。

## モジュール構成

| モジュール | 責務 |
|---|---|
| `app.py` | 標準ライブラリのみの HTTP サーバ（127.0.0.1 空きポート）。Edge `--app` 起動・`/quit` ビーコン・60 秒 idle watchdog |
| `resources/web/js/main.js` | エントリポイント。`Editor` 生成・`goPhase(1)`・`/quit` ビーコン・`/ping` ハートビート・`window.__editor` 公開 |
| `resources/web/js/editor.js` | `Editor` クラス本体。セッション状態・ウィザード・選択・ドラッグ・Undo/Redo・rAF 描画スケジューラ |
| `resources/web/js/editor-io.js` | SVG 読込（`load` / `abortLoad`）・保存（`bakeSvg`）・ファイル選択と D&D の入出力の関所 |
| `resources/web/js/editor-render.js` | オーバーレイ（ハンドル）・インスペクタ（右パネル）・左レールの描画。状態は持たず `ed` を読み書き |
| `resources/web/js/editor-events.js` | 静的 UI 要素（ドロップゾーン / ツールバー / ステップバー / キーボード）への起動時イベント配線 |
| `resources/web/js/label-state.js` | `LabelState`: 1 ラベルの状態モデルと実 DOM 同期（`renderToDom` / `rebuildTextContent`） |
| `resources/web/js/pie-rules.js` | 円幾何と leader 既定配置の純粋関数（`parsePieGeometry` / `labelBox` / `isOutsidePie` 等。DOM 非依存） |
| `resources/web/js/svg-policy.js` | 未信頼 SVG の許可リスト（要素 / 属性 / 値文法）。`sanitizeSvg` が参照する述語のみで DOM 非依存 |
| `resources/web/js/constants.js` | `CONFIG` 定数・既定 leader スタイル・UI 文言・`INSPECTOR_ACTIONS` 操作表 |
| `resources/web/js/dom.js` | UI 要素 id 参照の一元化 |
| `resources/web/js/geom.js` | global `LeaderGeom` を ES モジュールへ橋渡し（再エクスポートのみ） |
| `resources/web/js/icons.js` | inline SVG アイコンとトースト通知 |
| `resources/web/js/utils.js` | 純粋ユーティリティ（`sanitizeSvg` / `hasFsAccess` / `STATE_FIELDS`） |
| `resources/web/lib/leader_geom.cjs` | DOM 非依存の leader 純粋関数（UMD）。ブラウザと vitest が同一実装を共有 |

## 中核原則

- **File System Access API は使わない**: `utils.js` の `hasFsAccess()` は**常に false**。VDI の
  管理された Edge ではネイティブピッカーがレンダラごとクラッシュするため、開く =
  `<input type=file>` + D&D、保存 = `Blob` ダウンロード固定（`openFiles` / `save`）。
- **Edge は特殊フラグ無しで起動**: 隔離 `--user-data-dir` や `--disable-gpu` を付けると VDI で
  窓ごとクラッシュした実績があり、既定 Edge と同じ構成で `--app=<URL>` のみ（`app.py`）。
- **サーバ寿命は Edge プロセスに縛らない**: Edge のコールド起動は自プロセスを再起動し初回
  プロセスが早期終了するため、終了は `/quit` ビーコン + `IDLE_TIMEOUT`（60 秒）watchdog に一本化。
- **編集状態は `STATE_FIELDS` に一元化**: `textTx` / `leaderPts` / `leaderVisible` / `fill` /
  `lineCount` / `nameScaleX` の 6 フィールドが Undo・リセット対象の全集合。項目追加はここ 1 箇所。
- **leader 幾何は `leader_geom.cjs` の純粋関数**（`clampPointToBox` / `parsePath` / `buildPath` /
  `parseTranslate` / `normColor`）。DOM 非依存でブラウザとテストが同一実装を共有する。
- **leader 点列の不変条件**: 先頭アンカーはスライス中心角リム点へ常時ロック（`sliceMidAnchor`、
  `renderToDom` が毎回固定し UI もドラッグ不可）。末尾端点は必ずラベル外枠上
  （`snapEndpointToFrame` = `clampPointToBox`）。
- **自動 / 手動 leader の区別は `_auto` フラグ**: 手動でハンドルを動かした leader は位置駆動
  ルール（`applyRimLeaderRule`）が二度と上書きしない。自動分のみ円内で除去・円外で再生成。
- **描画は rAF スケジューラに合流**: 変更は `markDirty` でフラグを立てるだけにし 1 フレーム最大
  1 回反映。DOM を読む前は `flushNow()` で同期確定。
- **保存は非破壊**: `bakeSvg` が `transform` を `x`/`y` へ焼き込み、編集用要素
  （`[data-editor]` 等）を除去したクリーン SVG を書き出す。元ファイルは上書きしない。

## セキュリティ（2026-08-04 追加）

- **同一オリジン検査は `parse_request()` の 1 箇所だけに置く。** ハンドラ本体や
  ディスパッチャ側に書かない（書き忘れる／危険メソッドの列挙はブロックリストになる）。
- 許可は `127.0.0.1:<port>` / `localhost:<port>` の**完全一致 2 つのみ**。`startswith`・
  部分一致・正規表現を使わない（前方一致バイパスの排除）。`Origin: null` は許可しない。
- **CORS ヘッダ（`Access-Control-Allow-Origin` 等）は将来も出さない。** 出さないこと自体が
  防御で、許可外オリジンのプリフライトを必ず失敗させる。
- `do_GET` / `do_HEAD` に副作用を持たせない。安全メソッドは Origin を要求しないため、
  副作用を置くと CSRF が素通りする。
- **未信頼 SVG は `svg-policy.js` の構成的許可リストで濾す。** 要素名・属性名を許可制にし、
  名前空間プレフィックスを畳んでから判定する。**URL 値を取る属性（`href` / `xlink:href` /
  `src`）は 1 つも許可しない**（スキーム判定を存在させないこと自体が防御であり、判定を
  書き足さない。生き残った属性値が URL として解釈されることが無いので、`javascript:` 等の
  スキーム文字列を正規表現で弾く処理そのものが不要になる）。denylist へ戻さない（`<foreignObject>` の XHTML
  `<iframe srcdoc>`・`<animate attributeName="href">`・`xl:href`・制御文字入りの `javascript:`
  変種の 4 経路が実 Chromium で実行確認されている）。
- **保存で消える属性は入力からも落とす**: `data-` 接頭辞属性は前方一致で原則許可し、
  エディタ専有名（`RESERVED_DATA_ATTRS`。現行は `data-editor` / `data-editor-hit` /
  `data-editor-sel`）だけを減算して落とす。これらは `bakeSvg` が保存時に無条件削除する
  エディタ内部用の印なので、入力側から持ち込ませると「読み込み時は表示されるのに保存すると
  消える」不整合になる。
- **選択マーカーを予約 `data-*` にする理由**: 選択マーカーは `class="is-selected"` ではなく
  予約名 `data-editor-sel` を使う。`class` は値を検査しない許可属性なので、素のクラス名は
  出口の `sanitizeSvg` の検知網に掛からない。予約 `data-*` へ寄せておけば、`bakeSvg` の
  除去列挙が漏れても出口検査が `removedCount>0` で必ず保存を止める。
- 許可外のマークアップは削除したうえで**件数を利用者へ通知する**（黙って消さない）。
- **未信頼 SVG の受け入れには資源上限を置く**（2026-08-06 追加）。入力長 8MiB
  （`MAX_SVG_INPUT_CHARS`）だけでは「小さなノードを大量に詰める」形を止められないので、
  ノード数（`utils.js` の `MAX_SVG_NODES`）とラベル数（`CONFIG.maxLabels`）でも切る。
  超過は**部分的に読まず読込ごと拒否**し、件数を利用者へ通知する（一部だけ編集できる状態を
  作ると、保存時に欠けたまま書き出される）。
- **読込の中断は必ず空状態へ倒す**（`editor-io.js` の `abortLoad`）。`load` は先頭で `ed.name` /
  履歴を新ファイルへ切り替えるため、途中で止めるとキャンバスだけ旧ファイルのまま残り、
  そのまま保存すると**旧内容が新ファイル名で書き出される**。サニタイザの想定外例外もここへ
  倒す（`load` は `async` なので、投げると unhandled rejection として黙殺される）。
- **攻撃者が綴れる文字列でオブジェクトの表を引くときは自前キーだけを見る**。
  `svg-policy.js` の `FONT_FACE_VALUE` は `__proto__: null` で作り、参照側も
  `Object.hasOwn` で守る（素の表だと `constructor` / `__proto__` が継承値を返し、
  「未知＝拒否」ではなく TypeError になって上記の中断経路を踏む）。
- **Origin 検査だけでは frame 埋め込みを防げない**（2026-08-06 追加）。攻撃者ページが本アプリを
  `<iframe>` すると、frame の中で動くのは**アプリ自身**で、その `pagehide` が撃つ `/quit`
  ビーコンの Origin は完全一致する（同経路の `/ping` で idle watchdog も無効化できる）。
  対策は 2 枚: ①**全応答**（成功 `_send` と拒否 `_reject` の双方）へ `X-Frame-Options: DENY` +
  CSP `frame-ancestors 'none'` ほかの `SECURITY_HEADERS`、②`/quit` `/ping` に**起動ごとの
  セッショントークン**（`secrets.token_urlsafe(32)`）を要求する。
- **トークン検査も `parse_request()` の G6（トークン検査の段）だけに置く**。
  `hmac.compare_digest` の定時間・完全一致で、未設定サーバは全拒否（fail closed）。
  アプリへの受け渡しは `--app=` の URL クエリ 1 本。サーバへは `X-Session-Token` ヘッダで送り、
  ヘッダを付けられない `sendBeacon` だけがクエリ `?token=` で代替する。
  経路ごとの `if` を `do_POST` に書き足さない。
- **トークンを `ui.html` へ埋めない**（却下済み）。埋めると frame に埋め込まれた本アプリ自身が
  それを受け取り、`pagehide` の `/quit` が通って frame 埋め込みの経路がそのまま復活する。
  同じ理由で **`startup.log` にトークンを書かない**。安全メソッドはトークンを要求しないので、
  `do_GET`/`do_HEAD` には副作用も機微データも置かない。
- ⚠ Host 検査はポート探索オラクル（応答差からポート番号を当てられること）を塞がない
  （IP リテラル直指定の `Host` は許可値そのもの）。
  そこを鈍らせるのは `Cross-Origin-Resource-Policy: same-origin` であり、Host 検査が担うのは
  DNS リバインディングの遮断だけ。
- **接続の資源上限は「量」と「本数」の両方で持つ**（2026-08-07 追加）。`Handler.timeout`
  （= `REQUEST_TIMEOUT`）は**ガードの手前**を閉じる唯一の手段で（同一オリジン検査は
  リクエスト行とヘッダが届いて初めて走るため、無言の接続はガードに届かない）、
  `MAX_CONNECTIONS` は超過分をキューに積まず即切断する（`BoundedThreadingHTTPServer`）。
  拒否後の `_linger_close` の期限は per-recv でなく**接続単位**（per-recv だと
  「0.4 秒ごとに 1 バイト」でスレッドを握られる）。同じ理由で**要求の読み取り本体も接続単位の
  絶対期限で縛る**（`MAX_REQUEST_SECONDS` / `_DeadlineSocketIO`。各 recv の手前で残り時間へ
  タイムアウトを張り直す）。`Handler.timeout` は recv ごとに再武装される無通信上限なので、
  改行を送らず per-recv 未満の間隔で 1 バイトずつ送れば `readline` を無限に引き延ばせた。
- `app.py` の同一オリジン検査は pdf-to-svg `src/web/origin_guard.py` との**並行実装**。
  判定順・理由コード・許可リスト・テストベクタ・トークン機構・`SECURITY_HEADERS`・上記の
  資源上限・Edge 起動引数を逐語で揃え、**片方を変えたら必ず両方**
  （`leader_geom.cjs` ⇄ `leader_geometry.ts` と同じ運用）。
  drift は `test/test_parallel_impl_drift.py` が機械検出する（同じ検査を pdf-to-svg 側にも
  複製してあるのは、CI が片側だけ走る形（`ci:graph-editor` / `ci:pdf-to-svg`）だと検査が
  片側にしか無い場合に「変えた側では落ちない」ためで、この重複は意図的）。
  **共有の決めごとを足したら drift 検出の表にも足すこと**（`SECURITY_HEADERS` しか見て
  いなかった時期に、資源上限と Edge ログ既定 OFF の片側実装を実際に取りこぼした）。
  E2E の静的サーバ `test/editor_server.mjs` も同じ `SECURITY_HEADERS` を返す（CSP 下で UI が
  壊れていないことを実ブラウザで確かめるため）。
- 検証は `python -m pytest graph-editor`。`pnpm run ci:graph-editor` に組み込み済み。

## 却下済み / してはならないこと

- **FS Access API を復活させない**（`hasFsAccess()` を true に戻さない）: VDI クラッシュの実測に
  基づく決定。機能差は「保存先がダウンロードフォルダ固定」のみで、安定性を優先する。
- **Edge 起動フラグを増やさない**: 隔離 `--user-data-dir` + `--disable-gpu` は過去に VDI で
  クラッシュ（Edge ログ: GetGpuDriverOverlayInfo failed）。診断用 `--enable-logging` 系は
  **既定 OFF の opt-in**（`LABELEDITOR_EDGE_LOG`）で、既定 ON へ戻さない。既定プロファイルで
  開く設計上、利用者の Edge セッション全体の診断を利用者の端末へ書き続けることになるため
  （出力先も `%LOCALAPPDATA%` 配下に限り、起動ごとに作り直し・終了時に上限で切り詰める）。
- **サーバ終了を Edge の `proc.wait()` に縛らない**: `_watch_proc` は観測ログのみ。wait 終了に
  すると Edge コールド再起動で初回起動が空白になる退行を再現する。
- **pie-chart レンダラへの依存を持ち込まない**: `leader_geom.cjs` は独立実装で、pie-chart の
  `leader_geometry.ts` とは並行実装。ただし端点の BBox クランプ規約は合わせているため、幾何仕様を
  変えるときは pie-chart 側と突き合わせる。
